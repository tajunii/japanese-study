문장 독해 연습

その日ひ、夫おっとが、名古屋なごやの「味噌煮込みそにこみうどん」を食たべようといいだした。

그날, 남편이 나고야의 '미소 니코미 우동(된장 조림 우동)'을 먹자고 하기 시작했다.
  • 味噌煮込み : 1. 된장 조림 2. 된장 전골 (우동 등).
    ex) 寒い日には味噌煮込みが食べたくなる。(추운 날에는 된장조림이 먹고 싶어 진다)
  • 言い出す : 1. 생각해 내다; 상기[회상]하다; 떠올리다. 2. 생각하기 시작하다.
    ex) ああ、やっと思い出した。(아, 드디어 생각났어) / 私の方が間違っているのではないかと思い出してきた。(내가 틀렸을지도 모른다는 생각이 떠올랐다)

食欲しょくよくをそそるパッケージの写真しゃしんではなく、消費期限しょうひきげんが近ちかづいていることに気付きづいたからである。

식욕을 자극하는 포장 사진 때문이 아니라, 소비기한이 가까워지고 있다는 사실을 알아차렸기 때문이다.
  • そそる : 1. (식욕·흥미 등을) 돋우다 2. 자아내다 (눈물 등).
    ex) 美味しそうな匂いが食欲をそそる。(맛있는 냄새가 식욕을 돋우다) / 彼の話は興味をそそる。(그의 이야기는 흥미를 돋운다)
  • パッケージ : 1. 패키지, 포장 2. 일괄 (포괄적인 상품 묶음).
    ex) パッケージのデザインが可愛い。(포장 디자인이 예쁘다) / 旅行のパッケージツアーを予約した。(패키지여행을 예약했다)
  • ～ではなく : ~가 아니라.
  • 近づく(ちかづく) : 1. 가까워지다, 다가오다 2. 친해지다, 접근하다.
    ex) 台風が近づいている。(태풍이 다가오고 있다) / 試験の日が近づく。(시험일이 다가오고 있다)
  • 気付く(きづく) : 1. 알아차리다, 깨닫다 2. 정신을 차리다 (의식을 되찾다)
    ex) 間違いに気付く。(실수를 깨닫다) / 彼の変化に気付いた。(그의 변화를 눈치챘다)

ならば、といろどりやバランスを考かんがえつつ、ニンジンや椎茸しいたけ、カマボコ、たまご、などを冷蔵庫れいぞうこから取とり出だした。

그렇다면 하고, 색감과 영양의 균형을 생각하면서 당근, 표고버섯, 어묵(가마보코), 달걀 등을 냉장고에서 꺼냈다.
  • ならば : 1. 그렇다면, 그렇다면야 2. ~라면 (가정형)
  • いろどり : 1. 채색 2. 색의 배합 3. 구색
    ex) ポスターの彩りがよい(포스터의 색감이 좋다)
  • バランス : 여기서는 영양 균형.
  • ～つつ : 1. ~하면서. 2. 하면서도
    ex) 思いつつ歩く(생각하면서 걷다) / 失礼とは知りつつもお願いするのです(실례인 줄 알면서도 부탁드리는 것입니다)
  • 取り出す : 1. 꺼내다. 2. 골라내다.
    ex) ポケットから財布を取り出す(포켓에서 지갑을 꺼내다) / スイカの種を取り出す (수박씨를 발라 내다)

それらを見みて、夫おっとは牛肉ぎゅうにくとネギを忘わすれるな、という。

그것들을 본 남편이 소고기와 파를 빼먹지 말라고 한다.
  • 忘れるな : 잊지 마라. (강한 명령형)
  • ～という : "~라고 말한다."

あわてて冷凍れいとうしていた赤身あかみの牛肉ぎゅうにくを電子でんしレンジに入いれ、解凍かいとうスイッチを押おす。

서둘러 냉동해 두었던 살코기 소고기를 전자레인지에 넣고 해동 버튼을 눌렀다.
  • 慌(あわ)てる : 1. 당황하다, 허둥대다. 2. 서둘러 ~하다; 몹시 서두르다.
    ex) 慌てずにゆっくりやれ!(당황하지 말고 천천히 해) / 慌てて帰って行った(서둘러 돌아갔다)
  • 赤身 : 1. 살코기 2. 붉은 생선의 살 3. 재목의 중심에 있는 붉은 부분;심재

そこまで準備じゅんびをしたところで、屋外おくがいに保存ほぞんしているネギを取てりに出でた。

거기까지 준비를 마친 뒤, 밖에 보관해 둔 파를 가지러 나갔다.
  • ～したところで : ~한 시점에서, ~까지 하고 나서.

段取だんどりの悪わるさに我われながらあきれつつ、農家のうかさんからいただいた自慢じまんのネギの束たばの中なかから何本なんぼんか選えらんだ。

일의 순서를 제대로 짜지 못한 자신이 스스로도 한심하다고 생각하면서, 농가에서 받은 자랑거리인 파 한 단 가운데 몇 대를 골랐다.
  • 段取り : 1. 일을 진행시키는 순서·방도 2. 줄거리의 전개나 구성
    ex) 段取りの悪さ(준비나 순서가 서툰 것) / 段取りがつく(일의 준비가 다 되다)
  • 我ながら : '나 스스로 생각해도'. 자연스럽게는 '나도 내 자신이 어이가 없지만', '스스로도' 정도의 뉘앙스.
    ex) 我ながら恥ずかしい(나로서도 부끄럽다)
  • 呆(あき)れる : 1. (너무나 의외여서) 놀라다; 어이[어처구니]없다; 기막히다; 질리다.
  • - あきれつつ : 질리다, 어이없어하다의 ～つつ형. "어이없어하면서도", "한심하게 여기면서도".
    ex) 呆れて物も言えない(어처구니가 없어 말도 안나온다)
  • いただく : 1. 이다 2. 받들다 3. ‘もらう’의 공손한 말씨
    ex) 雪を頂く山山(꼭대기에 눈이 덮인 산들) / 会長に頂く(회장으로 받들다) / お土産を頂く(선물을 받다)
  • 自慢(じまん) : 자랑
    ex) 自慢話を一くさりやる(자랑을 한바탕 늘어 놓다)
  • - 自慢のネギ : 직역하면 "자랑의 파". 여기서는 '아끼는 파', '자랑거리인 파'라는 의미입니다. 글쓴이가 농가에서 직접 받은 좋은 파라 애착이 있는 것입니다.
  • 束(たば) : 다발, 묶음
    ex) 花束(꽃다발) / ネギ一束(파 한 단)
    ～か 불확정 표현(정도, 쯤, 대충). 何本か選んだ(대충 몇 뿌리 골랐다 라는 뉘앙스)
    ex) いくつかある(몇 개 있다) / 何人か来た(몇 명이 왔다) / どこか行く(어딘가 간다)
