학습 메뉴

これは、５時じを知しらせる音楽おんがくです。学校がっこうでは、この音楽おんがく가聞きこえたら家いえに帰かえりなさい、とよく教おしえています。
日本にほんでは、小学生しょうがくせい以上いじょうになっていれば、子こどもたちだけで外そとで遊あそんだりします。
なので、この音楽おんがくは役やくに立たちます。夏なつは、夕方ゆうがた６時じに流ながれます。
夏なつは日ひが長ながい、つまり、明あかるい時間じかん가長ながいからです。
流ながれる音楽おんがく는、地域ちいきによって違ちがいます。今いま、流ながれていたのは『夕焼ゆうやけ小焼こやけ』という有名ゆうめいな曲きょくです。

해석

이것은 5시를 알리는 음악입니다. 학교에서는 이 음악이 들리면 집에 돌아가라고 자주 가르칩니다.
일본에서는 초등학생 이상이 되면 아이들끼리만 밖에서 놀기도 합니다.
그래서 이 음악은 도움이 됩니다. 여름에는 저녁 6시에 흘러나옵니다.
여름에는 해가 길다, 즉 밝은 시간이 길기 때문입니다.
흘러나오는 음악은 지역에 따라 다릅니다. 지금 흘러나오고 있던 것은 '유야케 코야케(노을빛 꼬마 노을)'라는 유명한 곡입니다.

공부할 단어

浴あびる (1. (물, 햇빛 등을) 끼얹다/쏘이다, 2. (비난, 찬사 등을) 한몸에 받다) - ex) 毎朝まいあさシャワーを浴あびます。(매일 아침 샤워를 합니다.)

返かえす (1. 돌려주다/반환하다, 2. 되돌리다) - ex) 図書館としょかんに本ほんを返かえします。(도서관에 책을 돌려줍니다.)

被かぶる (1. (모자 등을) 쓰다/뒤집어쓰다, 2. 떠맡다/입다) - ex) 帽子ぼうしを被かぶる。(모자를 쓰다.)

役やくに立たち (1. 도움이 됨, 2. 유용함) - ex) 日本語にほんごの勉強べんきょうに役やくに立たちます。(일본어 공부에 도움이 됩니다.)

夜更よふかし (1. 밤늦게까지 자지 않음/밤샘, 2. 늦잠) - ex) 夜更よふかしは健康けんこうによくないです。(밤샘은 건강에 좋지 않습니다.)

苦くるしい (1. 괴롭다/아프다, 2. 답답하다/어렵다) - ex) 息いきが苦くるしいです。(숨이 가쁩니다 / 숨쉬기 괴롭습니다.)

오늘의 문법

～たら (1. ~하면, 2. ~했더니)

쓰임새: 동사나 형용사의 가정형에 연결되어, 어떤 조건이 충족되었을 때의 결과나 가정을 나타냅니다.

ex) 家いえに帰かえったら、すぐお風呂ふろに入はいます。(집에 가면 바로 목욕을 합니다.)

～になっていれば (1. ~가 되어 있으면, 2. ~ 상태가 되어 있다면)

쓰임새: 명사 뒤에 'になる'의 상태 지속 형태인 'になっている'의 가정형 'いれば'를 접속시켜, 어떤 조건이나 자격을 갖추고 있음을 가정합니다.

ex) 小学生しょう가くせいになっていれば、いつでも出でられます。(초등학생이 되어 있다면 언제든 나갈 수 있습니다.)

～たりする (1. ~하기도 하다, 2. ~하거나 하다)

쓰임새: 여러 동작이나 상태를 나열하거나, 대표적인 동작 하나를 예시로 들어 그러한 행위를 함을 나타냅니다.

ex) 週末しゅうまつは映画えいがを見みたりします。(주말에는 영화를 보기도 합니다.)

～つまり (1. 즉, 2. 결국/요컨대)

쓰임새: 앞서 말한 내용을 다른 말로 바꾸어 알기 쉽게 설명하거나 요약할 때 문두에 사용합니다.

ex) 彼女かのじょは母ははの妹いもうと、つまり叔母おばです。(그녀는 어머니의 여동생, 즉 이모입니다.)

～によって違います (1. ~에 따라 다릅니다, 2. ~에 의해 달라집니다)

쓰임새: 기준이나 상황, 대상에 따라 그 뒤의 결과가 달라짐을 나타낼 때 사용합니다.

ex) 人ひとによって考かんがえ方かた가違ちがいます。(사람에 따라 생각하는 방식이 다릅니다.)

전체

A 파트

B 파트

A: このお肉にく、高たかいだけあっておいしいですね。 이 고기, 비싼 만큼 맛있네요.

B: うん。ほんとにおいしいよね。 응, 정말 맛있다.

A: やっぱりおいしいもの食たべてる時ときが、一番いちばん幸しあわせだな。 역시 맛있는 걸 먹고 있을 때가 제일 행복해.

B: そういえば、ダイエットするとか言いってなかった？ 그러고 보니 다이어트한다고 말하지 않았어?

A: あれ、そんなこと言いいましたっけ？ 어라, 제가 그런 말을 했었나요?

B: うん。言いってたけど？ 응, 말했었는데?

A: 食たべたいものを我慢がまんしてまで、ダイエットするのは、もうやめようと思おもって。 먹고 싶은 걸 참아가면서까지 다이어트하는 건 이제 그만두려고 해서요.

B: ふうん。そうなの？まあ、無理むりしないに越こしたことはないけど。 흐음, 그래? 뭐, 무리하지 않는 게 제일 좋지만.
